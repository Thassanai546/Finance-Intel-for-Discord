<h1>Finance Intel Discord Bot</h1>

A simple Discord bot for retrieving financial data and stock-related information using slash commands. The bot integrates with a custom ```finance_data``` module to fetch and display relevant financial data.

<h2>Features</h2>

+ Check Bot Status: Ensure the bot is online with /pingfin.
+ Trending Stocks: View trending stock information from Yahoo Finance.
+ Company Details: Fetch detailed information about a company using its stock ticker.
+ Financial Data: Retrieve financial details for a given stock.
+ 52-Week High/Low: Get the 52-week high and low for a specific stock.
+ Stock Recommendations: Obtain stock recommendations for informed decision-making.
